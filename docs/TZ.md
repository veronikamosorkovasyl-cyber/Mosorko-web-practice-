## 1. Призначення проєкту

### 1.1. Мета сайту

Створити веб-сайт кінотеатру, на якому відвідувач за кілька кроків проходить шлях від афіші до вибору конкретних місць на інтерактивній схемі залу та бронювання квитків. Усе відбувається на одному сайті, без переходів на сторонні сервіси.

Проєкт вирішує проблеми, виявлені в аналізі конкурентів: сеанси і ціни не показані на головній сторінці, вибір місця відбувається на іншому домені, масштабування сторінки заблоковане, інтерфейс застарілий і перевантажений. Конкурентна перевага: наочна схема залу зі статусами місць, миттєвий підрахунок суми та mobile-first інтерфейс.

### 1.2. Цільова аудиторія

**Основна:** молодь і студенти 16–30 років. Користуються переважно смартфоном, хочуть швидко обрати сеанс і зручні місця (наприклад, по центру залу або поруч із друзями).

**Додаткова:**

- сім'ї з дітьми 30–45 років (місця поруч, віковий рейтинг і тривалість фільму);
- пари, які обирають вечірній сеанс і місця для двох;
- люди з особливими потребами (доступність, навігація клавіатурою, екранні читачі).

### 1.3. Ключові сценарії використання

**Сценарій 1. Швидке бронювання місць на вечірній сеанс (основний).**
Користувач відкриває сайт зі смартфона → бачить афішу з найближчими сеансами → обирає фільм і сеанс → на схемі залу вибирає 2 сусідні місця → бачить загальну суму → заповнює форму (ім'я, телефон, email) → отримує підтвердження бронювання.

**Сценарій 2. Пошук фільму на вихідні.**
Користувач заходить до каталогу фільмів → фільтрує за жанром, датою й часом → відкриває сторінку фільму (опис, тривалість, віковий рейтинг, трейлер, сеанси) → порівнює час і ціну → переходить до вибору місць.

**Сценарій 3. Бронювання з урахуванням зайнятих місць.**
Користувач обирає сеанс і бачить, які місця вже зайняті (їх не можна вибрати) → обирає кілька місць, може скасувати вибір → якщо передумав, повертається до іншого сеансу, і обрані місця скидаються. Якщо місце встигли зайняти, сайт показує повідомлення про помилку й пропонує обрати інше.

## 3. Структура сторінок (карта сайту)

```
Головна (/)
├── Афіша / Каталог фільмів (/movies)
│   └── Сторінка фільму з розкладом сеансів (/movies/:id)
│        └── Вибір місць на схемі залу (/sessions/:id)
│             └── Оформлення бронювання (/booking/:sessionId)
│                  └── Підтвердження бронювання (/booking/success)
├── Розклад сеансів (/schedule)
├── Контакти (форма зворотного зв'язку) (/contacts)
└── 404 (сторінка не знайдена)
```

| Сторінка | Маршрут | Призначення |
| --- | --- | --- |
| Головна | `/` | Афіша найближчих сеансів, популярні фільми, посилання на каталог |
| Каталог фільмів | `/movies` | Картки фільмів, пошук, фільтри за жанром і датою |
| Сторінка фільму | `/movies/:id` | Опис, трейлер, тривалість, віковий рейтинг, список сеансів |
| Схема залу | `/sessions/:id` | Інтерактивний вибір місць, підрахунок суми |
| Бронювання | `/booking/:sessionId` | Форма з даними покупця |
| Підтвердження | `/booking/success` | Деталі бронювання і номер |
| Розклад | `/schedule` | Усі сеанси на обрану дату |
| Контакти | `/contacts` | Форма зворотного зв'язку, адреса, карта |
| 404 | `*` | Сторінка помилки з посиланням на головну |

## 4. Функціональні вимоги

| № | Вимога |
| --- | --- |
| ФВ-1 | **Афіша.** Сайт показує каталог фільмів у вигляді карток: постер, назва, жанр, тривалість, віковий рейтинг. |
| ФВ-2 | **Пошук і фільтрація.** Пошук за назвою (debounce 300 мс), фільтри за жанром і датою сеансу. |
| ФВ-3 | **Сторінка фільму.** Опис, трейлер, тривалість, віковий рейтинг, список найближчих сеансів із часом, залом і ціною. |
| ФВ-4 | **Інтерактивна схема залу.** Після вибору сеансу відображається схема з рядами й місцями. Кожне місце має статус: вільне, зайняте, обране. |
| ФВ-5 | **Вибір і скасування місць.** Клік по вільному місцю обирає його, повторний клік скасовує вибір. Зайняті місця вибрати неможливо. Максимум 8 місць в одному бронюванні. |
| ФВ-6 | **Підрахунок суми.** Під схемою показано перелік обраних місць (ряд, місце) і загальну вартість; значення оновлюється після кожного кліку. |
| ФВ-7 | **Форма бронювання.** Поля: ім'я, телефон (+380…), email, коментар, згода з умовами. Валідація на клієнті (під час введення й при відправці) та на сервері. Кнопка недоступна, доки форма не заповнена коректно. |
| ФВ-8 | **Збереження бронювання.** Сервер перевіряє, що місця ще вільні, зберігає бронювання й позначає місця як зайняті. Якщо місце вже зайняте, повертається помилка з пропозицією обрати інше. |
| ФВ-9 | **Підтвердження.** Сторінка з деталями: фільм, сеанс, зал, місця, сума, номер бронювання. |
| ФВ-10 | **Форма контактів.** Надсилання повідомлення (`POST /api/contact`), відповідь 201 або 400 зі списком помилок. |
| ФВ-11 | **Тема оформлення.** Перемикач світлої та темної теми із збереженням вибору в `localStorage`. |
| ФВ-12 | **Керування сеансами (CRUD).** API дозволяє створювати, переглядати, змінювати й видаляти сеанси (основна сутність за варіантом). |
| ФВ-13 | **Стани інтерфейсу.** Для завантаження даних передбачені стани «завантаження», «помилка» і «немає даних». |

## 5. Нефункціональні вимоги

**Адаптивність**

- mobile-first, коректне відображення на ширинах 360, 768 і 1280 px;
- схема залу зручна для дотику на смартфоні (мінімальний розмір цілі натискання 44×44 px).

**Швидкодія**

- Lighthouse (mobile): Performance, Accessibility, Best Practices, SEO — кожен ≥ 90;
- зображення у форматі WebP із заданими `width`/`height`, `loading="lazy"`;
- code splitting для маршрутів (`React.lazy`).

**Доступність**

- семантична HTML5-розмітка, один `h1` на сторінці;
- повна навігація клавіатурою, зокрема вибір місць на схемі (Tab, Enter, Space);
- `aria-label` для кожного місця (наприклад, «Ряд 5, місце 7, вільне»);
- контраст тексту ≥ 4,5:1 (WCAG AA), видимий фокус, посилання «skip to content»;
- масштабування сторінки не заблоковане;
- axe DevTools: 0 критичних помилок.

**Безпека**

- валідація всіх даних на сервері;
- налаштування і секрети в `.env` (файл у `.gitignore`, у репозиторії — `.env.example`);
- налаштований CORS.

**Супровід**

- публічний репозиторій GitHub, щонайменше 30 змістовних комітів (`feat:`, `fix:`, `docs:`);
- автодеплой із гілки `main`, README з описом, скриншотами та інструкцією запуску.
